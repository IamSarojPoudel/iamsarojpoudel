**Software engineer working on backend systems, cloud infrastructure and mobile apps.**

At [BlueStone Africa](https://bluestone.africa), I build a cloud platform that helps facilities and property teams manage their assets. I joined in 2024 as the first developer and built it from scratch with React, Node.js and MongoDB. Since then it has grown into Go microservices on Azure, with a mobile app that technicians use in the field.

#### What I work on

- Multi-tenant Go microservices that communicate through a message broker, with configuration and data isolated per client
- PostgreSQL partitioning and Redis caching that keep queries fast as data grows
- Containerised services on Kubernetes, with CI/CD pipelines that test and deploy to Azure
- Monitoring and alerting, along with role-based access control
- A mobile app for asset verification and maintenance, with offline mode, QR scanning and planned inspections
